How to Play

⬆️➡️⬇️⬅️

Use the arrow keys or touch controls to move the player through each puzzle and reach every checkpoint.

📦

Push Boxes

Push every box onto a checkpoint square to complete the level.

Use the arrow keys on the keyboard/ swipe to the desired direction to move the player around the grid. The next level will load when all boxes are placed on checkpoints. If you get stuck, click the Reset Level button on the right to restart the level.

✅

Game Flow

Use undos, skips, and restarts to help you along the way.

📱

About the game

Sokoban is a popular puzzle game developed by Hiroyuki Imabayashi in 1981. The goal of the game is to move all boxes on the screen to their designated checkpoints.

This version was forked for Paskhaver on Github
